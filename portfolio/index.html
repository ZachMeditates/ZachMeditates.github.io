01

Good Report

A job search that reads the postings for you.

02

One master list from many messy sources

A master data hub built in Snowflake.

Problem
A large telecom data company had the same organizations typed hundreds of thousands of different ways across several sources, so it could not report on them reliably.
What I did
Wrote Python notebooks in Snowflake that pull the sources together, clean and match the names, and build one master list for reporting and processing.
Result
About 640,000 records and 350,000-plus differently typed names reduced to about 175,000 unique organizations.

Snowflake · Python · SQL

03

Filling the gaps between systems

Automatic record linking with Postman.

Problem
For the same company, hundreds of thousands of records were missing details that lived in other systems, and matching them by hand was not realistic.
What I did
Built Postman collections that pull data from several APIs, link a record automatically when the match is certain, and flag the rest for a person to review.
Result
Hundreds of thousands of records checked across multiple sources, with only the uncertain ones left for people.

Postman · REST APIs · Data quality

04

SAM.gov opportunity alert

Federal bids, found and ranked every weekday.

Problem
A federal contracting team searched SAM.gov by hand every day, and good bids still slipped past.
What I did
Set the fit rules with the team’s capture lead, then built a weekday scan of new bids under their nine target codes that scores each one High, Medium or Low and sends the ranked list to the team’s chat and inbox. It runs on free tools and raises an alert if a day is ever missed.
Result
More than 30 minutes of manual searching saved every day, with no paid software.

GitHub Actions · Power Automate · SAM.gov API

05

Government data feeds on Apify

Public records, cleaned up and watched for changes.

Problem
The data businesses want, like new liquor licenses, restaurant inspections and licensed professionals, is public but scattered: every state publishes it differently, and scrapers break without anyone noticing.
What I did
Built and run 12 public data tools that turn official registries into clean, deduplicated feeds and flag what changed since the last run, with health checks that catch a source quietly breaking. Two open-source libraries came out of the work.
Result
56 users so far, and over 99% of runs succeed. The cannabis feed alone covers 47 US states and territories plus Canada.
